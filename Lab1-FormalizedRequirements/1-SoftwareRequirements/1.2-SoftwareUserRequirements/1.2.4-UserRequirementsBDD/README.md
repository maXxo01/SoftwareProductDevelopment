### Вимоги користувача у форматі BDD

#### Feature: User authorization
As a user  
I want to authorize in the system  
So that I can access personalized safety information  

#### Feature: Threat notification
As a user  
I want to receive notifications about potential threats  
So that I can react in time  

#### Feature: Emergency assistance
As a user  
I want to send an emergency signal  
So that I can get help in dangerous situations
