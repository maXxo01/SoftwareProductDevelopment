### Use Case Diagram

Use Case Diagram відображає основні сценарії взаємодії користувача 
з програмним продуктом особистої безпеки.

Діаграма включає такі варіанти використання:
- Авторизація користувача
- Отримання інформації про рівень безпеки
- Отримання сповіщень про загрози
- Перегляд рекомендацій
- Надсилання сигналу тривоги
