# Лабораторна робота №5  
## Проєктування тестових сценаріїв програмного продукту

### Мета роботи
Метою лабораторної роботи є розробка тестових сценаріїв для перевірки
функціональних та нефункціональних вимог програмного продукту
у сфері особистої безпеки.

### Об’єкт тестування
Функціональність реєстрації користувача в системі особистої безпеки.

### Результат
У результаті виконання лабораторної роботи розроблено UML-діаграму
програмних класів, визначено прототипи методів та створено набір
тестових сценаріїв.
