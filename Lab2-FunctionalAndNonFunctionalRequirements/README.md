# Лабораторна робота №2  
## Визначення функціональних та нефункціональних вимог  
## і планування процесу розробки програмного продукту

### Дисципліна
Технології створення програмних продуктів

### Тема
Програмний продукт для забезпечення особистої безпеки

### Мета лабораторної роботи
Метою лабораторної роботи є визначення функціональних та нефункціональних
вимог до програмного продукту у сфері особистої безпеки, а також виконання
початкового планування процесу його розробки.

### Об’єкт дослідження
Програмний продукт, призначений для забезпечення особистої безпеки користувачів
шляхом інформування, попередження та підтримки у потенційно небезпечних ситуаціях.

### Предмет дослідження
Функціональні та нефункціональні вимоги, взаємодія людини з комп’ютером,
архітектура програмного продукту та планування процесу розробки.

### Результат
У результаті виконання лабораторної роботи сформовано структурований набір
функціональних та нефункціональних вимог, визначено тип архітектури програмного
продукту та виконано планування процесу його розробки.
