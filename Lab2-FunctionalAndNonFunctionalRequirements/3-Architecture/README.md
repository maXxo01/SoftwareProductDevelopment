# Архітектура програмного продукту

Програмний продукт належить до архітектурного типу мобільного застосунку.

## Рівні архітектури
- Рівень представлення: мобільний інтерфейс користувача
- Рівень бізнес-логіки: обробка сигналів безпеки та логіка оповіщення
- Рівень даних: зберігання персональних даних та інформації про місцезнаходження

## Обґрунтування вибору
Мобільна архітектура забезпечує швидкий доступ до системи, роботу в режимі
реального часу та оперативне інформування, що є критично важливим для
забезпечення особистої безпеки.
